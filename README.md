# 🎮 Sobre o Portfólio

Como usuário frequente da **Steam**, busquei inspiração no design da plataforma para criar uma identidade visual única para este portfólio. O objetivo é demonstrar minhas habilidades em desenvolvimento web e apresentar meus projetos em um ambiente temático.

## 🛠️ Tech Stack & Ferramentas

* **HTML5 & CSS3:** Estrutura e estilização visual.
* **VS Code:** Ambiente de desenvolvimento.
* **IA Generativa:** Utilizada para auxiliar e acelerar a escrita dos códigos de estilo.
